- **3D coin animation**

- **Heads / Tails selection**  
  Choose your side before each flip. You can switch between Heads and Tails whenever you like, as long as the coin is not currently spinning.

  All flips use demo credits only. The panel tracks:
  - total wagered amount,
  - profit or loss vs. initial bankroll,
  - sample RTP (return-to-player),
  - number of flips,
  - win rate,
  - best winning streak.

- **Flip history list**  
  A scrollable history area shows the result of each flip, the chosen side and the net outcome in demo credits.
